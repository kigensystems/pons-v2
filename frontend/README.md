# Frontend

React + TypeScript + Vite. Three.js and React Three Fiber are installed for the upcoming opening scene.

Use Node.js 24. Run `npm ci`, then `npm run dev` from this directory. Run `npm run build` for TypeScript checks and production output, `npm run lint` for Oxlint, and `npm run preview` to serve the production build locally.

The current screen only confirms initialization. No 3D renderer or model is wired up yet. See the [project brief](../docs/PROJECT-BRIEF.md) before implementing the scene.
