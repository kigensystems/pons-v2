# Frontend

React, TypeScript, Vite. Routes: `/` opening scene (Macintosh artwork with a canvas TV, composited lighting, static grain), `/explore` (alias `/launch`), `/about`. The earlier Three.js scene and its Blender sources are preserved but not loaded.

Commands, install notes, and the inspection workflow are in the root [AGENTS.md](../AGENTS.md) and [CLAUDE.md](../CLAUDE.md). Asset provenance: [public/ASSETS.md](public/ASSETS.md).
